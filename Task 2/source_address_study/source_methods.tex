\hypertarget{observation-unit-and-evidence}{%
\subsubsection{Observation unit and
evidence}\label{observation-unit-and-evidence}}

The observation unit is one unique decoded Bitcoin input source address
with one fixed reference payment. The case cohort comprises 500
addresses whose payments entered the reported Coldcard collector in
blocks 960188-960191 on 30 July 2026 UTC. Five later registry sources
are kept outside this study. An address is neither a verified
individual, a device nor an independent incident.

The target is \texttt{known\_\allowbreak{}coldcard\_\allowbreak{}core\_\allowbreak{}membership}: 1 for these
500 fixed core sources and 0 for the selected sources outside the core
and other case exclusions. The latter are operational comparisons, not
certified legitimate or non-hardware addresses. All independently
verified compromise and signing-device labels remain unknown. One
exactly mapped owner report is retained as reported evidence, separate
from verified labels.
\href{https://github.com/somaxbt/coldcard-drain-addresses/tree/1e7fef87060808c29beaf9d137eb5ff9e37f8811}{SomaxBT's
reconstruction} and
\href{https://github.com/alva-p/coldcard-weak-rng-research/tree/f93cfed16302bb91c8409fdee9ce5576a34b7e52}{Alvaro
P.'s reconstruction} corroborate all 500 source/payment relations. They
observe the same chain and do not provide 500 independent owner
confirmations. Their exact pinned files and attribution caveats remain
in the repository's corroboration record.

\hypertarget{acquisition-sampling-and-coverage}{%
\subsubsection{Acquisition, sampling and
coverage}\label{acquisition-sampling-and-coverage}}

The source registry reuses the supplied transaction corpus. The
same-block comparison census uses four complete, height/hash-anchored
Blockchain.info block responses collected on 30 October. The census
contains 5,526 distinct source addresses before exclusions and 5,025
eligible comparisons. A deterministic salted hash ranking selects 1,000
sources, with a two-comparisons-per-case quota in each reference-block
stratum. No source is replaced after a collection failure or incomplete
history. The census, selection and normalized evidence are public;
private raw caches are not redistributed.

Address histories use the recorded Blockstream Esplora API route.
Full-history pagination/counter audits and, where necessary, the
separately validated anchored pre-cutoff collector support the published
prefixes. That anchored method matched both prefixes and all fourteen
variables for eight complete-history pilot controls across the four
blocks. Successful saved pages were reused only after fingerprint and
cursor-sequence checks. Provider reconciliation is not cryptographic
inclusion verification. This report performs no new provider requests.

Exactly 1,378 vectors are available: 500 cases and 878 comparisons. The
122 remaining comparison prefixes are bounded-incomplete, with null
vectors and no model score. They are retained in the selected population
but excluded from fitting and scoring. Full-current-history coverage is
a different measure: 864 comparison histories are complete and 136
incomplete. Fourteen of those incomplete current histories nevertheless
have an exhausted, validated prior prefix.

\hypertarget{predictor-boundary-and-definitions}{%
\subsubsection{Predictor boundary and
definitions}\label{predictor-boundary-and-definitions}}

For a reference at height h, only confirmed transactions with height
strictly less than h enter a feature. The whole reference block and all
future data are excluded. This uses block heights, not timestamps or
within-block transaction order. Reference-payment inputs, values, fees,
recipients and UTXO-depletion outcomes remain outside the predictors, as
do raw/hash identifiers, labels, collection counters and evidence
metadata.

fee rates stay missing; they are not zero, the reference-payment fee, or

available vector from 35,323 normalized address/transaction
observations.

\hypertarget{frozen-grouping-and-model}{%
\subsubsection{Frozen grouping and
model}\label{frozen-grouping-and-model}}

Connected components combine repeated source-address hashes, shared
prior-transaction references, common reference TXIDs and identical
fourteen-variable vectors including missingness. These 918 observed-link
components are overlap safeguards, not proven ownership groups. Unknown
prior links through the 122 excluded histories are not claimed absent.

Each component uses the lexical minimum address SHA256. SHA256 of the
fixed prefix \texttt{coldcard-\allowbreak{}source-\allowbreak{}split-\allowbreak{}v1:42:} followed by that
minimum hash determines a residue modulo ten: 0-6 for training, 7 for
validation and 8-9 for test. Every partition has at least 20 rows of
each membership class, with no measured component/shared-link group
crossing partitions. No seed reroll or component splitting is used.

One prespecified \texttt{DecisionTreeClassifier} is fitted on 1,033
training rows: Gini criterion, maximum depth 3, minimum 20 rows per
leaf, balanced training class weights and random seed 42. Each of the
fourteen original variables uses its observed training median; zero is a
fallback only for an entirely missing training column. Fourteen fixed
missingness indicators accompany the variables. Validation/test rows do
not fit this preparation, select features/parameters/thresholds or enter
a final all-row refit.

The exported score is a class-balanced training leaf proportion. Its
field is \texttt{case\_\allowbreak{}membership\_\allowbreak{}score}. The membership decision
includes every score \textgreater= 0.5. The three prespecified
comparators are constant training membership prevalence, descending
prior inactivity and descending prior balance. Undefined comparator
values use the same training-only median fill. Comparators have ranking
metrics only.
