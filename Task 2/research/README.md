# Research implementation and saved case results

Use the [numbered parts](../README.md) to learn the project. This directory is the technical workspace behind them.

- [coldcard/](coldcard/README.md): transaction extraction, classroom classifier, grouped validation, fund-flow analysis and historical outputs.
- [external_cases/](external_cases/README.md): sourced external references, collection tools and evidence/role reviews. These do not automatically establish hardware-wallet labels.

Code and its original result folders remain together to keep imports and reproducibility simple. The part guides link directly to the relevant reports; you do not need to inspect every file here.
