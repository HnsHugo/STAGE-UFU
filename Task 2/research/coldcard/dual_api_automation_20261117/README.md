# Hourly recovery to 1,500 complete feature vectors

Hugo explicitly authorizes automatic per-provider failover and hourly future executions. This supersedes older no-schedule/no-provider-switch instructions for NEW scopes only; historical protocols and failures remain immutable. Old schedules remain disabled. No model, paid service, proxy/IP/account change, or main-branch merge.

The bridge contract in ../dual_api_frontier.py is provider-neutral and covered in both directions by offline tests. It rewinds strictly above the partial boundary block and follows the chosen provider's native TXID cursor, merging immutable-equal overlaps only. There is no constant numeric index offset. The sorted union is never a native continuation cursor. Controlled overlap is required to prove no omissions and does not count as fresh coverage.

**Readiness limitation:** the new helper is not a standalone network collector. Its callbacks must be connected to a provider-specific journaled/guarded GET and atomic durable checkpoints, then integrated with the existing feature/funding closure, independent audit, private backup and remote lease machinery before the first automatic switch. No live reverse-direction switch has been claimed or executed by this setup. The scheduled agent must complete and verify that integration before switching; it may continue an existing audited provider-native path when eligible. Never replace the provider string in a pinned old protocol or collector.

At every tick: restore the latest Git state and fingerprinted private layers; acquire the single global lock together with every historical collector lock and publish/read back the global lease. If a collector is alive or ownership uncertain, exit without provider traffic. Do not trust ps visibility across tool sessions. Reconcile unclosed successful response journals before any new acquisition; save them privately at the earliest opportunity. Keep an unknown outcome explicit and inside its old attempt budget. If restoring bytes fails, do not fetch them again.

Select only rows missing from the latest verified 1,500-row feature view. Persist separate eligibility/backoff/native-frontier records per provider and source. HTTP503/429/network failure stops its current scope and sets that provider's cooldown; honor Retry-After, use the existing conservative 429 backoff. HTTP403 excludes that provider pending access review. If both are unavailable, save state and let the next hourly execution reassess. Do not manufacture access by changing transport.

Freeze a fresh scope for every unit. One worker, 5.25-second recorded UTC/monotonic spacing, 45-second timeout, up to fifty added page intents/source/unit including failed and unknown attempts. Journal before dispatch, hash/save bodies before advancing the actual native cursor, snapshot after every accepted page, audit and durably back up before publishing/promoting features. Never promote unfinished evidence. Preserve every existing complete vector, strict pre-block cutoff, identity and unknown label. Stop after a reasonable checkpoint before the execution budget ends and leave a persisted handoff. A later tick resumes the actual saved frontier, never the consumed scope.

Disable the single automation only after all 1,500 complete vectors are independently audited and durably saved and the final commit is read back. Notify Hugo only for actual progress, completion or a blocker requiring action. Scheduled execution is best effort, not a guaranteed continuously running service.
